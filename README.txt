CONTENTS
- index.html: all website text and sections
- style.css: responsive design and colors

PREVIEW ON YOUR COMPUTER
1. Extract this ZIP to a folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. To edit the site, open the folder in VS Code and edit index.html / style.css.

IMPORTANT BEFORE PUBLISHING
1. In index.html, replace:
   [Add your email address]
   [Add your profile URL]
   YOUR-EMAIL@example.com
2. Review all project descriptions so they accurately reflect your current work.
3. Add only real publications, results, affiliations, awards, or partnerships that you can substantiate.
4. Do not publish personal information you do not want public.

FREE PUBLISHING OPTION: GITHUB PAGES
1. Create a free account at https://github.com/
2. Create a new public repository. A repository name like "md-abdul-aziz-research" is fine.
3. Upload index.html, style.css, script.js, and README.txt to the repository's root.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose the main branch and /(root), then Save.
7. GitHub will show the published website URL after deployment finishes. The URL normally looks like:
   https://YOUR-USERNAME.github.io/md-abdul-aziz-research/
   This is an example pattern only; your actual URL depends on your GitHub username and repository name.

COST
This is a static website and can be hosted free on GitHub Pages. A custom domain is optional and usually costs money. Free hosting availability and platform terms can change.
